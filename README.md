# 우리 도서관

구글 드라이브에 쌓아둔 전자책을 아이패드·PC·폰에서 읽고, 식구들과 나눠 보는 앱.

브라우저에서 열면 그냥 되고, 홈 화면에 추가하면 앱처럼 열린다.

> **개인·가정 범위에서 쓰려고 만든 것이다.**
> 이 저장소에 책 파일은 들어 있지 않고 앞으로도 넣지 않는다.
> 책은 각자의 구글 드라이브에 있고, 앱은 그것을 보여줄 뿐이다.

---

## 나중의 나에게

몇 달 뒤에 다시 열었을 때 헤매지 않으려고 적어둔다.
**모르겠으면 이 문서의 「고칠 때 조심할 것」부터 읽어라.**

---

## 1. 무엇이 어디 있나

```
ebook-web/               ← 이 저장소. 앱 전부
  index.html             앱 하나. 전부 이 안에 있다 (약 4,000줄)
  sw.js                  서비스 워커. 고칠 때마다 V 를 올려야 한다
  manifest.json          홈 화면에 추가될 때 쓰는 정보
  icon-*.png             아이콘

깃허브 밖 (내 컴퓨터)
  서재도서관_전체통합본.gs   Apps Script 에 붙이는 것. 이것 하나뿐이다
  우리도서관_계획.md         앞으로 할 것
  남은일_목록.md            자잘한 숙제
```

**앱은 파일 하나다.** CSS 도 JS 도 index.html 안에 있다.
빌드 도구도 없고 설치할 것도 없다. 고쳐서 올리면 끝이다.

## 2. 어떻게 돌아가나

```
   기기 (index.html)
        │
        │  ① 목록을 받는다        ┌──────────────────┐
        ├─────────────────────▶ │  Apps Script     │
        │                        │  (웹앱)          │
        │  ② 모임 칸을 읽고 쓴다  └────────┬─────────┘
        ├─────────────────────▶          │
        │                                 ▼
        │                        ┌──────────────────┐
        │                        │  스프레드시트    │
        │                        │  책 목록 · 모임  │
        │                        └──────────────────┘
        │
        │  ③ 책 파일을 직접 받는다
        └─────────────────────▶  구글 드라이브 (읽기 전용)
```

**세 곳을 오간다.**

| | 무엇을 | 어디에 |
|---|---|---|
| Apps Script | 책 목록(색인), 모임 칸 | 스프레드시트 |
| 구글 드라이브 | 책 파일 자체 | 원래 있던 폴더 |
| 각자의 드라이브 | 읽은 곳·형광펜·메모 | 앱 전용 숨은 칸 |

읽은 기록은 **서버로 가지 않는다.** 각자 자기 드라이브의 `appDataFolder` 에
들어가므로, 서로의 진도나 밑줄은 볼 수 없다.

---

## 3. 값은 어디에 있나

**소스에는 없다.** 이 저장소는 공개돼 있으므로 일부러 비워두었다.

```js
const DEF={ url:'', tok:'', cid:'...(공개돼도 되는 값)', fol:'', adm:'' };
```

| 값 | 사는 곳 | 바꾸는 법 |
|---|---|---|
| 웹앱 주소 | 기기 + 내 구글 계정 숨은 칸 | 앱 → 관리 |
| 토큰 | Apps Script 속성 + 위와 같음 | `SET_WEBAPP_TOKEN()` |
| 관리자 열쇠 | Apps Script 속성 + 위와 같음 | `SET_ADMIN_KEY()` |
| 스프레드시트 ID | .gs 파일 안 | 거기서 직접 |

**설정은 내 구글 계정에도 함께 담긴다.** 새 기기에서는 로그인만 하면
주소·토큰·열쇠가 저절로 내려온다 (관리 → [구글 계정에서 설정 가져오기]).
숨은 칸은 계정마다 따로라, 식구가 로그인해도 그쪽 칸에는 아무것도 없다.

**토큰과 열쇠는 스크립트 속성에 있으므로 바꿔도 재배포가 필요 없다.**
지금 값이 궁금하면 Apps Script 에서 `SHOW_KEYS()`.

식구에게는 **초대 링크**로 준다. 주소·토큰·이름이 링크에 실려 있어
누르는 것만으로 설정이 끝난다.

## 4. 무엇을 할 수 있나

**읽기**

- EPUB · PDF · TXT 를 앱 안에서 연다
- 좌우로 넘기거나 위아래로 흘려보거나
- 형광펜 네 색 + 메모. 글자 크기를 바꿔도 자리를 지킨다
- 읽어주기 (🔊) — 기기 목소리로 EPUB·TXT·PDF 를 지금 자리부터. 읽는 문장 표시, 쪽 따라 넘김,
  빠르기·목소리, 취침 타이머. 읽는 동안 화면이 안 꺼지게 잡는다
- 목차 — EPUB 은 책에 든 것, PDF 는 개요, TXT 는 '제1장 · 1화 · 프롤로그 · [3화]' 같은 줄을 찾아 만든다
- 종이색 넷 (밝게 · 세피아 · 어둡게 · E-Ink), 글자 굵기, 아래 줄 숨기기
- TXT 끊긴 줄 잇기 — 화면에서만. 원본 파일은 그대로
- 책갈피 (막대의 🔖). 형광펜과 같은 HL 칸에 `k:'bm'` 으로 산다
- 모은 형광펜 · 책갈피 — 홈 아래 바로가기. 모든 책을 색·메모·검색으로 찾고 누르면 그 자리로
- PDF 에 애플펜슬로 필기. 지우개는 그은 데만 지운다
- 받아두면 인터넷 없이도 읽힌다

**찾기**

- 정렬: 제목 · 저자 · 출간일 · 최근 읽음 · 크기 · 담긴 날짜, 그리고 [거꾸로]
- ⚡ 조건 서가 — 검색어·상태·분류·정렬을 저장. 홈 '내 서가' 줄에 뜬다 (8개까지, 기기끼리 맞춤)
- 독서 달력 — 날마다 읽은 시간과 책. 홈 아래 바로가기
- 폴더 탭 — 드라이브에 정리한 폴더를 그대로 둘러본다. [실시간 | 색인] 을 고른다
  - 실시간: 드라이브에 바로 묻는다. 새로 넣은 책이 BUILD_INDEX 없이 보인다 ('새로' 표시)
  - 색인: 받아 둔 목록의 경로로 나무를 짠다. 빠르고 인터넷 없이도 된다
  - 인터넷이 없거나 로그인 전이면 실시간이 저절로 색인으로 넘어간다
  - 폴더 안 책도 ☰ 정렬을 따른다 ('제목'은 파일 이름순, '담긴 날짜'는 드라이브에 넣은 날)
  - 폴더 통째로 받아두기 (아래 폴더는 받지 않는다)
- 37,000권에서 글자를 칠 때마다 즉시 (미리 정렬해 두어 17ms)
- 대·중·소분류, 저자, 출판사

**나누기**

- 모임을 나눈다 — 우리집 · 형제자매처럼. 서로 안 섞인다
- 서가를 만들어 책을 꽂아둔다
- 서로에게 권한다, 없는 책을 요청한다
- 링크를 잘못 보냈으면 그 사람만 끊는다

**기기끼리**

- 읽은 곳·형광펜·메모·서가가 아이패드와 PC 사이를 오간다
- 펜슬 필기와 받아둔 파일은 기기마다 따로 (너무 커서)

## 5. 고칠 때 조심할 것

**★ sw.js 의 V 를 반드시 올려라.**

```js
const V = 'ebl-v34.2';   // ← 이것
const BUILD = 'v34.2';   // ← index.html 의 이것도 같이
```

안 올리면 **아무리 고쳐도 옛 화면이 그대로 나온다.**
여러 번 당했다. 앱에서 [앱 새로 고치기] 를 눌러도 마찬가지다.

**★ Apps Script 는 '새 배포' 를 누르지 마라.**

```
배포 → 배포 관리 → 연필(편집) → 버전: 새 버전 → 배포     ○
배포 → 새 배포                                          ✗ 주소가 바뀐다
```

주소가 바뀌면 모든 기기가 한꺼번에 멈춘다.

**★ 이름이 겹치는지 보라.**

(v31 에서도 `COLL` 이 겹쳐 `EXCOLL` 로 바꿨다. 이미 있던 이름이다.)

index.html 은 파일 하나라 위쪽 상수와 아래쪽 상수가 부딪히기 쉽다.
`const PAGE=60` 과 새로 만든 `const PAGE={...}` 로 앱 전체가 안 뜬 적이 있다.
겹치면 **화면이 '시작하는 중…' 에서 멈춘다.**

**★ 형광펜만 셀 때는 `hlOnly()` 를 써라.**

v30 부터 책갈피도 `HL[책ID]` 안에 들어 있다. `hlOf()` 는 둘 다 돌려준다.
형광펜 개수·지우기·복사에 `hlOf()` 를 쓰면 책갈피까지 딸려간다.

**★ 책 받는 길은 `SRC` 하나뿐이다.**

`getBook()` 은 `SRC[b.s||'drive'].open()` 만 부른다. NAS(WebDAV) 를 붙일 때는
`SRC.dav` 를 더하고 그 책들에 `s:'dav'` 와 `dav:/…` 이름표를 주면 된다.
`s` 가 없는 책은 모두 드라이브다 — 지금까지의 기록이 그래서 이어진다.

**★ 책 정보는 신뢰도로 거른다 (v34.2 · Apps Script v15).**

색인의 n(신뢰도) 이 '낮음·의심' 이면 알라딘 짝이 엉뚱한 경우가 많다.
앱 ☰ '책 정보' [확실한 것만 | 알라딘 그대로 | 파일 이름] — 처음 값은 확실한 것만.
확실한 것만: 높음·중간·실패·없음은 그대로, 낮음·의심은 원제(o)로 보이고 표지·저자·분류를 비운다.
찾기(HAY)에는 원래 알라딘 제목도 남긴다 — 화면에서만 내린다. 원래 값은 b._0 에 있다.
Apps Script 는 `BUILD_INDEX_v15_교체용.gs` 로 바꾼다 (claude 폴더). v15 색인은
r='1'(알라딘 안 씀), h(검색용 알라딘 제목, 낮음만) 칸이 붙어 오고, 앱은 그대로 둔다.

**★ 폴더 탭은 색인의 제목·표지를 쓰지 않는다 (v34.1).**

색인 제목·표지는 알라딘에서 찾아 붙인 것이라, 짝을 잘못 지은 책이
폴더에 없는 다른 책처럼 보였다. 실시간은 실제 파일 이름, 색인은 색인 제목에 '색인 정보' 표시.
표지는 둘 다 끈다 (`exShow`). '새로' 는 색인을 만든 뒤 드라이브에 들어온 파일에만.
→ 다른 탭(전체·읽는 중…)의 엉뚱한 제목·표지는 Apps Script 의 알라딘 짝짓기를 손봐야 고쳐진다.

**★ 탐색기의 시작점은 관리 → '도서 폴더' 링크다.**

비어 있으면 실시간이 안 되고 색인으로만 보인다.
한 번 연 폴더는 `ebl_dirs` 에 기억한다 (1.5MB 넘으면 오래된 것부터 버림).
도서 폴더 이름은 `ebl_rootname` 에 한 번 받아 둔다. 폴더 이름을 바꿨으면 이 칸을 지워라.
색인 모드는 모든 책 경로의 맨 앞 한 겹이 같으면 그것을 도서 폴더로 본다.
NAS 는 `DIRSRC` 에 `list()` · `name()` 을 가진 갈래 하나를 더하면 된다.

**★ TXT 정리(`txtClean`)는 글자 수를 바꾸면 안 된다.**

TXT 형광펜은 글자 위치(c.s~c.e)로 저장된다. 정리는 줄바꿈→빈칸,
남는 빈 줄→U+200B 처럼 한 글자를 한 글자로만 바꾼다.
그래서 원문/정리본을 오가도 형광펜이 같은 자리에 있다. 길이가 바뀌는 규칙을 넣지 마라.

**★ 목록을 새로 받으면 정렬표(`ORD`)를 버린다.**

v31 까지는 안 버려서, 기기에 둔 목록 → 새 목록으로 바뀔 때
엉뚱한 순서로 보이고 새 책이 빠지기도 했다. `apply()` 맨 앞에서 비운다.

**★ 읽은 시간(`DAYS`)은 기기마다 따로 센다.**

`DAYS['날짜']['책ID|기기']=초`. 볼 때 더하고, 맞출 때는 칸마다 큰 값.
같은 칸을 두 기기가 같이 늘리면 겹쳐 세게 된다 — 기기 번호(`ebl_dev`)를 빼지 마라.
15초마다 세고, 5분 넘게 손을 안 대면 멈춘다. '기록 안 함' 책은 안 센다.

**★ 시작할 때 일찍 불릴 수 있는 값은 `var` 로 둔다.**

홈·폴더 탭은 앱이 다 읽히기 전에 그려질 수 있다. 아래쪽에서 `let/const` 로 만든 값을
거기서 쓰면 TDZ 로 멈춘다. v33 의 `DAYS`·`SORTN`·`TABN` 이 그래서 `var` 다.

**★ 읽어주기는 한 문장씩 준다.**

길게 주면 크롬은 15초쯤에서 끊고, 사파리는 pause/resume 이 불안하다.
그래서 문장(200자 안쪽)마다 `speak()` 하고, 멈춤은 `cancel()` 뒤 그 문장부터 다시 읽는다.
`TTS.gen` 번호로 취소된 문장의 onend 가 다음 문장을 부르지 않게 막는다.
문장 표시(`ttsShow`)가 실패해도 읽기는 계속된다 — 감싸 둔 try 를 빼지 마라.

**★ 최상위에서 `ME` 를 건드리지 마라.**

`let ME` 는 3,500줄쯤에 있다. 그보다 위에서 `ME.grp=...` 를 쓰면
TDZ 로 스크립트가 통째로 죽는다. 이것도 당했다.

## 6. 확인하는 법

고친 뒤 이것들을 돌리면 위의 사고를 대부분 잡는다.

```
문법 · id 참조 · 빈 버튼         index.html 을 훑는다
진짜로 뜨는지 (jsdom)            TDZ·이름겹침을 잡는다  ← 제일 중요
설정 화면 오가기                 뒤로·닫기·권한별 단추
로그인 이어가기                  닫았다 열기, 만료, 계정 여럿
Apps Script 통로                가짜 GAS 로 doGet 을 실제로 부른다
```

마지막 것이 특히 값어치가 있다. 배포하지 않고도
**다른 모임 글이 안 섞이는지**를 확인할 수 있다.

## 7. 문제가 생기면

| 증상 | 볼 곳 |
|---|---|
| 고친 게 안 보인다 | sw.js 의 V 를 올렸나 |
| '시작하는 중…' 에서 멈춤 | 이름 겹침. 화면에 줄 번호가 나온다 |
| 목록이 안 온다 | 관리 → 기록. 토큰이 맞나 |
| 로그인이 자꾸 풀린다 | 기본설정의 '구글 로그인' 줄에 까닭이 적힌다 |
| `Unexpected token '<'` | 웹앱 주소가 비었다. 자기 자신을 부른 것 |
| 기기를 바꿨다 | 관리 → [구글 계정에서 설정 가져오기] |
| 모임이 안 보인다 | 관리자 열쇠가 들어 있나 (`isOwner()`) |
| 모임 칸이 비어 있다 | Apps Script `FAM_SHOW()` |

## 8. Apps Script 함수

편집기 왼쪽에서 골라 실행한다. 밑줄로 시작하는 것은 목록에 안 나온다.

```
[책 모으기]
  START_FROM_EXTRACT   추출부터 알라딘까지
  CONTINUE  STOP  STATUS
  INSTALL_WATCHDOG     끊기면 자동으로 이어간다
  BUILD_INDEX          시트 → 색인 파일 (앱이 이걸 받는다)

[열쇠]
  MAKE_TOKEN           쓸 만한 토큰을 지어준다
  SET_WEBAPP_TOKEN     토큰 바꾸기
  SET_ADMIN_KEY        관리자 열쇠 바꾸기
  SHOW_KEYS            지금 값 보기

[모임·차단]
  FAM_SHOW             모임·시트·사람 한눈에
  FAM_RESET            모임과 명단 지우기 (시트는 남음)
  BLOCK_LIST           끊긴 사람 보기
  BLOCK_CLEAR          모두 풀기
```

## 9. 쓴 것들

CDN 에서 받아 쓴다. 설치는 없다.

```
epub.js 0.3.93    EPUB 읽기
pdf.js 3.11.174   PDF 읽기 · 필기
JSZip             EPUB 은 사실 zip 이다
Google Identity   로그인
```

**epub.js 의 아이패드 버그**(issue #904) 때문에 글 고르기가 한 글자로
줄어드는 일이 있어, 형광펜은 epub.js 의 주소(CFI)를 안 쓴다.
대신 **앞 40자 + 그은 글 + 뒤 40자** 로 자리를 찾는다.
리눅스 Foliate 가 epub.js 를 버리고 택한 방식과 같다.
