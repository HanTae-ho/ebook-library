# 우리 도서관

구글 드라이브에 쌓아둔 전자책을 아이패드·PC·폰에서 읽고, 식구들과 나눠 보는 앱.

브라우저에서 열면 그냥 되고, 홈 화면에 추가하면 앱처럼 열린다.

> **개인·가정 범위에서 쓰려고 만든 것이다.**
> 이 저장소에 책 파일은 들어 있지 않고 앞으로도 넣지 않는다.
> 책은 각자의 구글 드라이브에 있고, 앱은 그것을 보여줄 뿐이다.

---

## 나중의 나에게

몇 달 뒤에 다시 열었을 때 헤매지 않으려고 적어둔다.
**모르겠으면 이 문서의 「고칠 때 조심할 것」부터 읽어라.**

## 1. 무엇이 어디 있나

```
ebook-web/               ← 이 저장소. 앱 전부
  index.html             앱 하나. 전부 이 안에 있다 (약 4,000줄)
  sw.js                  서비스 워커. 고칠 때마다 V 를 올려야 한다
  libarchive-web.js      RAR·7z 해제 도구 (v36). 손으로 고치지 않는다
  hanja-eum.js           한자 → 한글 음 (v40, npm hanja 1.1.5 MIT, 84KB). 처음 필요할 때 받는다
  libarchive.wasm        그 엔진. 처음 RAR·7z 를 열 때만 받아 온다
  manifest.json          홈 화면에 추가될 때 쓰는 정보
  icon-*.png             아이콘

깃허브 밖 (내 컴퓨터)
  서재도서관_전체통합본.gs   Apps Script 에 붙이는 것. 이것 하나뿐이다
  우리도서관_계획.md         앞으로 할 것
  남은일_목록.md            자잘한 숙제
```

**앱은 파일 하나다.** CSS 도 JS 도 index.html 안에 있다.
빌드 도구도 없고 설치할 것도 없다. 고쳐서 올리면 끝이다.

## 2. 어떻게 돌아가나

```
   기기 (index.html)
        │
        │  ① 목록을 받는다        ┌──────────────────┐
        ├─────────────────────▶ │  Apps Script     │
        │                        │  (웹앱)          │
        │  ② 모임 칸을 읽고 쓴다  └────────┬─────────┘
        ├─────────────────────▶          │
        │                                 ▼
        │                        ┌──────────────────┐
        │                        │  스프레드시트    │
        │                        │  책 목록 · 모임  │
        │                        └──────────────────┘
        │
        │  ③ 책 파일을 직접 받는다
        └─────────────────────▶  구글 드라이브 (읽기 전용)
```

**세 곳을 오간다.**

| | 무엇을 | 어디에 |
|---|---|---|
| Apps Script | 책 목록(색인), 모임 칸 | 스프레드시트 |
| 구글 드라이브 | 책 파일 자체 | 원래 있던 폴더 |
| 각자의 드라이브 | 읽은 곳·형광펜·메모 | 앱 전용 숨은 칸 |

읽은 기록은 **서버로 가지 않는다.** 각자 자기 드라이브의 `appDataFolder` 에
들어가므로, 서로의 진도나 밑줄은 볼 수 없다.

## 3. 값은 어디에 있나

**소스에는 없다.** 이 저장소는 공개돼 있으므로 일부러 비워두었다.

```js
const DEF={ url:'', tok:'', cid:'...(공개돼도 되는 값)', fol:'', adm:'' };
```

| 값 | 사는 곳 | 바꾸는 법 |
|---|---|---|
| 웹앱 주소 | 기기 + 내 구글 계정 숨은 칸 | 앱 → 관리 |
| 토큰 | Apps Script 속성 + 위와 같음 | `SET_WEBAPP_TOKEN()` |
| 관리자 열쇠 | Apps Script 속성 + 위와 같음 | `SET_ADMIN_KEY()` |
| 스프레드시트 ID | .gs 파일 안 | 거기서 직접 |

**설정은 내 구글 계정에도 함께 담긴다.** 새 기기에서는 로그인만 하면
주소·토큰·열쇠가 저절로 내려온다 (관리 → [구글 계정에서 설정 가져오기]).
숨은 칸은 계정마다 따로라, 식구가 로그인해도 그쪽 칸에는 아무것도 없다.

**토큰과 열쇠는 스크립트 속성에 있으므로 바꿔도 재배포가 필요 없다.**
지금 값이 궁금하면 Apps Script 에서 `SHOW_KEYS()`.

식구에게는 **초대 링크**로 준다. 주소·토큰·이름이 링크에 실려 있어
누르는 것만으로 설정이 끝난다.

## 4. 무엇을 할 수 있나

**읽기**

- EPUB · PDF · TXT 를 앱 안에서 연다
- 만화 CBZ · ZIP — 한 장 / 두 장 펼침 / 세로(웹툰), 넘김 방향, 두 번 눌러 확대, 밝기·대비·흑백,
  끝나면 같은 폴더 다음 권. 그림 없이 TXT·EPUB 가 든 ZIP 은 '안의 책' 목록 (TXT 는 한 권으로 잇기)
- 좌우로 넘기거나 위아래로 흘려보거나
- 형광펜 네 색 + 메모. 글자 크기를 바꿔도 자리를 지킨다
- 읽어주기 (🔊) — 기기 목소리로 EPUB·TXT·PDF 를 지금 자리부터. 읽는 문장 표시, 쪽 따라 넘김,
  빠르기·목소리, 취침 타이머. 읽는 동안 화면이 안 꺼지게 잡는다
- 목차 — EPUB 은 책에 든 것, PDF 는 개요, TXT 는 '제1장 · 1화 · 프롤로그 · [3화]' 같은 줄을 찾아 만든다
- 종이색 넷 (밝게 · 세피아 · 어둡게 · E-Ink), 글자 굵기, 아래 줄 숨기기
- TXT 끊긴 줄 잇기 — 화면에서만. 원본 파일은 그대로

  '이 책에서 되풀이되는 줄' 을 보고 골라 넣는다. 화면에서만

**찾기**

- 정렬: 제목 · 저자 · 출간일 · 최근 읽음 · 크기 · 담긴 날짜, 그리고 [거꾸로]
- ⚡ 조건 서가 — 검색어·상태·분류·정렬을 저장. 홈 '내 서가' 줄에 뜬다 (8개까지, 기기끼리 맞춤)
- 독서 달력 — 날마다 읽은 시간과 책. 홈 아래 바로가기
- 폴더 탭 — 드라이브에 정리한 폴더를 그대로 둘러본다. [실시간 | 색인] 을 고른다

  - 색인: 받아 둔 목록의 경로로 나무를 짠다. 빠르고 인터넷 없이도 된다
  - 인터넷이 없거나 로그인 전이면 실시간이 저절로 색인으로 넘어간다
  - 폴더 안 책도 ☰ 정렬을 따른다 ('제목'은 파일 이름순, '담긴 날짜'는 드라이브에 넣은 날)
  - 폴더 통째로 받아두기 (아래 폴더는 받지 않는다)
- 37,000권에서 글자를 칠 때마다 즉시 (미리 정렬해 두어 17ms)
- 대·중·소분류, 저자, 출판사

**나누기**

- 모임을 나눈다 — 우리집 · 형제자매처럼. 서로 안 섞인다
- 서가를 만들어 책을 꽂아둔다
- 서로에게 권한다, 없는 책을 요청한다
- 링크를 잘못 보냈으면 그 사람만 끊는다

**기기끼리**

- 읽은 곳·형광펜·메모·서가가 아이패드와 PC 사이를 오간다
- 펜슬 필기와 받아둔 파일은 기기마다 따로 (너무 커서)

## 5. 고칠 때 조심할 것

**★ sw.js 의 V 를 반드시 올려라.**

```js
const V = 'ebl-v48';   // ← 이것
const BUILD = 'v48';   // ← index.html 의 이것도 같이
```

안 올리면 **아무리 고쳐도 옛 화면이 그대로 나온다.**
여러 번 당했다. 앱에서 [앱 새로 고치기] 를 눌러도 마찬가지다.

**★ Apps Script 는 '새 배포' 를 누르지 마라.**

```
배포 → 배포 관리 → 연필(편집) → 버전: 새 버전 → 배포     ○
배포 → 새 배포                                          ✗ 주소가 바뀐다
```

주소가 바뀌면 모든 기기가 한꺼번에 멈춘다.

**★ 이름이 겹치는지 보라.**

(v31 에서도 `COLL` 이 겹쳐 `EXCOLL` 로 바꿨다. 이미 있던 이름이다.)

index.html 은 파일 하나라 위쪽 상수와 아래쪽 상수가 부딪히기 쉽다.
`const PAGE=60` 과 새로 만든 `const PAGE={...}` 로 앱 전체가 안 뜬 적이 있다.
겹치면 **화면이 '시작하는 중…' 에서 멈춘다.**

**★ 형광펜만 셀 때는 `hlOnly()` 를 써라.**

v30 부터 책갈피도 `HL[책ID]` 안에 들어 있다. `hlOf()` 는 둘 다 돌려준다.
형광펜 개수·지우기·복사에 `hlOf()` 를 쓰면 책갈피까지 딸려간다.

**★ 책 받는 길은 `SRC` 하나뿐이다.**

`getBook()` 은 `SRC[b.s||'drive'].open()` 만 부른다. NAS(WebDAV) 를 붙일 때는
`SRC.dav` 를 더하고 그 책들에 `s:'dav'` 와 `dav:/…` 이름표를 주면 된다.
`s` 가 없는 책은 모두 드라이브다 — 지금까지의 기록이 그래서 이어진다.

**★ 알라딘은 끝났다 — 책 정보의 기본 출처는 YES24 (Apps Script v18, 2026-11).**

알라딘 OpenAPI 는 2026-10-30 까지였다. 그 전에 받은 정보는 시트에 그대로 있다.
v18 의 `doAladin_` 는 이름만 그대로이고 속은 YES24 다 (ISBN 조회 → 제목 검색, 전자책 포함).
시트의 '알라딘_…' 칸에 YES24 정보를 담는다. 매칭방식 칸 끝의 `·i12345` 가 YES24 상품번호,
색인의 `y` 가 그것이다. 앱은 길게 눌러 'YES24 에서 보기' 로 출처·링크를 보인다.
분류는 YES24 에 없어서 그 ISBN 으로 국중도 KDC 를 묻는다 (국중도 키가 있을 때만).
'못 찾은 책 다시 물어보기' 는 이제 지우지 않는다 — 더 나은 결과가 나올 때만 바꾼다.
YES24 에 제목·저자·표지 저장을 확인받았다 (답은 따로 보관). 거두라고 하면 `Y24_STORE=false`.

**★ 도서관 홈 (v48).** `buildHome` 끝에서 `paintLibHome`. 특집은 서가 줄의 `값` 에 `{feat:1,d,tag}` — 고칠 때 `값` 을
통째로 덮으므로 `unpackVal` 로 읽어 합친 뒤 `packVal` (그래야 `g` 가 안 사라짐). 공지는 모임 칸 `kind:'note'`.
오늘의 책 소개(`TINTRO`)는 메모리에만 — 저장하지 않는다 (YES24 약관). 시안: 디자인 화면 '우리 도서관 — 새 홈 시안'.

**★ 읽기 자는 덮는 층 하나 (`#ruler`, v47).** 글·형광펜을 건드리지 않는다. 띠 자리 `P.rulerY`(화면 비율), 높이 `P.rulerH`(줄 수 ×
`15px×글자크기×줄간격`), 어둡기 `P.rulerD`. EPUB·한 쪽씩 PDF 는 쪽을 넘기면 `rulerTop`. `P.ruler===2` 는 막대까지 숨김.

**★ 남은 시간 (v46).** 책: `bookSec`(DAYS 합) ÷ 진도 × 남은 진도 (5분·3% 넘어서부터). 장(EPUB): 쪽 넘긴 간격(`PGT`, 3초~5분만)의
가운데 값 × `loc.start.displayed` 의 남은 쪽. 저장 공간 한도는 `SIZES`(ebl_sizes: 크기·마지막으로 연 때, 기기마다) 로 셈하고
한도의 90% 까지 비운다 — 다 읽은 책 → 30일 넘게 안 연 책 순, 사흘 안에 연 것과 지금 책은 남김. 내려받기 JSON 에서 `cfg` 는 뺀다.

**★ 아이 칸은 `BOOKS_ALL` → `kidFilter` → `BOOKS` (v44).** `apply()` 가 원래 목록을 `BOOKS_ALL` 에 두고 거른 것을 `BOOKS` 로.
규칙은 모임 칸 `kind:'kid'`(id `kid-번호`, 대상=그 사람)에서 `kidSync` 가 받아 `ebl_kid` 에 기억. 폴더 탭은 '색인' 으로만.
Apps Script v18.14 부터 kid 줄은 관리자만 쓰고 지운다. 집 안 울타리일 뿐, 기기를 잘 아는 사람이 풀 수는 있다.
**★ 서로의 서재는 기본 끔 (v44).** 켜면 `read-번호` 한 줄에 책ID·진도만 (제목 안 보냄, 받는 쪽이 색인에서 찾음).
끄면 그 줄을 지운다. `P.shareRead` 는 `shr`·`shrAt` 로, 명단 `MATES` 는 `mates`·`matesAt` 로 동기화.
`BOOKS_ALL`·`KIDR` 은 `apply` 가 쓰므로 `var`.

**★ EPUB 형광펜 자리 (v43).** `quoteOf` 가 `q.o`(장 안 비율)를 더 적는다. `findQuote` 는 ① 장(`q.h`)이 다르면 안 찾고
② 앞뒤까지 맞는 곳이 딱 하나면 그곳 ③ 아니면 `pickQuote` — 앞뒤 글이 닮은 정도 + `q.o` 에 가까운 정도로 고른다.
예전 형광펜(`q.h`·`q.o` 없음)은 예전처럼 찾는다. 텍본 문구 `P.jpat` 는 `jp`·`jpAt`(ebl_jpatat)으로 동기화.

**★ 별점은 `RV` (v42, ebl_rv).** 동기화 상태에 `rv` 로 실려 나중에 고친 쪽이 이긴다. 지우면 `{s:0,t:'',at}` 로 남긴다.
모임에 보이기는 모임 칸 `kind:'rv'` — id 가 `rv-사람번호-책해시` 라 고치면 같은 줄이 바뀐다 (Apps Script 고칠 것 없음).
**★ 옵시디언 보내기는 `obsidian://new … &append=true` (v42).** 노트 이름은 플러그인의 `safeName` 과 같은 규칙(`obSafe`).
보낸 형광펜에 `ob` 를 적는다 — 그 뒤에 고치거나 새로 그은 것만 '새로 그은 것만' 에 든다. 6만 자가 넘으면 복사 + 노트 열기.

**★ 전집 안쪽 책의 이름표는 `바깥ID#안쪽경로` (v35~, v41 에서 목록에 씀).** 그래서 권마다 읽은 기록·형광펜이 따로 산다.
바깥 ZIP 의 `RD[바깥ID].l` 에 마지막으로 연 안쪽 경로를 적는다 (`innerMark`) — 홈 '읽는 중' 에 바깥 ZIP 이 뜨고,
다시 열면 그 폴더 + [이어 읽기]. 목록은 `innerList`/`drawInner` 하나로 ZIP 과 RAR·7z 를 함께 그린다.
다음 권(`NEXTVOL`)은 `markRead` 가 다 읽음이 되는 순간 `nextVolOffer` 로 권한다 (만화 권은 만화 뷰어가 따로).
`NEXTVOL`·`ZIL` 은 `markRead` 가 일찍 부를 수 있어 `var`.

**★ 한자 음은 화면을 바꾸지 않는다 (v40).** 읽어주기(`ttsSpeak` 의 `hanjaRead`)와 글 고르기 막대 미리보기에서만.
화면에 음을 달면(ruby) 글자 수가 달라져 형광펜 자리가 어긋난다. 사전(`hanja-eum.js`)은 첫 음만 있어
음이 여럿인 글자는 `HANJA_IN`(낱말 안)·不(ㄷ·ㅈ 앞 '부') 처럼 따로 적는다.
대사 나누기는 `splitChunks` 끝의 `splitQuotes` — 문장 조각을 따옴표 경계에서 한 번 더 자르고 `q:1` 을 단다.
" 는 번갈아 세고, 영어의 ' 는 쓰지 않는다.

**★ 단축키는 `readerKey` 하나로 (v39).** 바깥 문서와 EPUB 안쪽(iframe, `bindGestures`) 둘 다 여기로 온다.
입력 칸에서는 안 먹는다. 판(.pan)·장(.sheet)이 열려 있으면 Esc 로 닫기만, 다른 키는 안 먹는다.
휠(`readerWheel`)은 EPUB · 한 쪽씩 PDF · 만화(세로 보기 빼고)에서만 쪽을 넘기고, TXT 와 흘려보는 PDF 는 그냥 굴린다.
옆 단추(3·4)는 mouseup 에서 막아야 브라우저가 뒤로 가지 않는다 (auxclick 도 막음).

**★ 텍본 쓰레기 문구도 글자 수를 한 자도 바꾸지 않는다 (v38).**
줄 잇기(`txtClean`)와 같은 약속이다. 지울 글자는 U+200B 로 바꾼다. 그래야 형광펜 자리(`c.s~c.e`)가
원문·정리본 어느 쪽으로 보든 맞는다. 순서는 `txtShown()` 안에서 **쓰레기 문구 → 줄 잇기**.
설정이 바뀌면 `TXTC=''` 로 버리고 다시 만든다 (`txtRepaint`).
넣은 문구는 `P.jpat` (기기마다, 동기화 안 함). '글 그대로' 는 그 글만, '/모양/' 은 그 모양이 든 줄을 통째로.
`TXTJN`(지운 곳 수)은 `applyRead` 에서 일찍 불릴 수 있어 `var` 다.

**★ 이어 읽기는 받아둔 책만 저절로 연다 (v38).** 받지 않은 책을 시작하자마자 열면 구글 로그인 창이
'손으로 누르지 않은 창' 이라 막힌다. 그래서 [이어 읽기] 단추를 띄운다. 초대·공유 링크(#s=…)로 열면 하지 않는다.

**★ YES24 는 Apps Script 를 거쳐서만 (v37 · Apps Script v17).**

YES24 약관: 키를 앱(클라이언트)에 넣지 말 것, 대량 수집해 별도 DB 를 만들지 말 것, 보여 줄 때 출처·링크.
- 앱 '책 소개 (YES24)' → 웹앱 mode=y24 → Apps Script 가 묻고 결과만. 6시간 캐시, 앱은 창 닫으면 버림.
- 짝짓기: 알라딘이 실패·의심·낮음이면 YES24 로 ISBN 만 찾아 알라딘 ISBN 조회 (`doAladin_` v17).
  YES24 자료는 시트에 안 남긴다. 돌리는 법은 원래의 '못 찾은 책 다시 물어보기'.
- 키: 스크립트 속성 EBL_Y24KEY (`SET_YES24_KEY`). 하루 18,000회로 스스로 멈춤.
- 웹앱 doGet 에 `y24Route_` 두 줄이 들어가야 한다 → 배포 관리에서 '새 버전'. 안 하면 앱이 큰 응답을 끊고 안내한다.
- 옵시디언 플러그인 1.1.0 도 설정에 키를 넣으면 공식 API 로 (키는 그 기기 설정에만).

**★ RAR·7z 는 통째로 받아 푼다 (v36).**

ZIP 과 달리 필요한 장만 받을 수 없다. 300MB 까지만 연다 (아이패드 메모리).
종류는 이름이 아니라 첫 바이트로 가른다 (`sniffArc`) — CBR 인데 속이 ZIP 인 파일이 흔하다.
해제 도구 두 파일(libarchive-web.js · libarchive.wasm)만은 앱 본체 밖에 있다. 필요할 때만 불러온다.
다시 만들기:
```
npm i libarchive-wasm@1.2.0 esbuild
echo "module.exports=require('libarchive-wasm')" > entry.js
npx esbuild entry.js --bundle --format=iife --global-name=LibArchive --platform=browser \
    --external:fs --external:path --external:crypto --minify --outfile=libarchive-web.js
cp node_modules/libarchive-wasm/dist/libarchive.wasm .
```
7z 안의 한글 이름은 깨져 보인다 (wasm 쪽 로캘 문제). 숫자 순서는 지켜진다.

**★ 형식 갈래에 '만화·ZIP' 이 있다 (v36).** zip·cbz·cbr·rar·7z·cb7. 처음부터 켜져 있다.
Apps Script v16(`ZIP색인_v16_교체용.gs`)은 이 형식들을 색인에 넣되 알라딘에 묻지 않는다.

**★ '책 정보가 틀림' 은 책마다 (`WRONG`, 기기끼리 맞춤).** 진짜 표지(`COVERS`)는 EPUB 속 표지·만화 첫 장을
240px JPEG 로 줄여 IndexedDB kv 'covers' 에 둔다 — 이 기기에만. 카드는 진짜 표지를 알라딘 표지보다 먼저 쓴다.

**★ 만화 ZIP 은 통째로 받지 않는다 (v35).**

ZIP 끝의 목차(중앙 디렉터리)만 Range 로 받고, 장마다 그 그림만 받는다 (`driveSrc`).
드라이브가 Range 를 무시하고 통째로 보내면(200) 40MB 넘는 파일은 끊는다.
deflate 는 DecompressionStream('deflate-raw'), 없으면 한 조각짜리 ZIP 을 지어 JSZip 으로.
UTF-8 표시 없는 이름은 CP949 로 읽는다. 그림 주소(blob)는 24장만 들고 나머지는 놓는다.
150MB 넘는 만화는 폴더 '받아두기' 에서 뺀다. CBR(RAR)·7z 는 아직 못 연다.
v35.1: ZIP 안의 ZIP(권마다 묶은 전집)은 압축 안 한 채면 바깥 ZIP 의 그 구간을 그대로 읽는다 (`innerSrc`),
끝나면 같은 전집의 다음 권으로. 앞에 다른 데이터가 붙은 ZIP 은 목차 자리를 다시 잡는다.
열 것이 없으면 안에 든 확장자별 개수를 보여 주고, 관리 → 기록에도 'ZIP 열기: … (jpg 120, …)' 로 남긴다.

**★ 책 정보는 신뢰도로 거른다 (v34.2 · Apps Script v15).**

색인의 n(신뢰도) 이 '낮음·의심' 이면 알라딘 짝이 엉뚱한 경우가 많다.
앱 ☰ '책 정보' [확실한 것만 | 알라딘 그대로 | 파일 이름] — 처음 값은 확실한 것만.
확실한 것만: 높음·중간·실패·없음은 그대로, 낮음·의심은 원제(o)로 보이고 표지·저자·분류를 비운다.
찾기(HAY)에는 원래 알라딘 제목도 남긴다 — 화면에서만 내린다. 원래 값은 b._0 에 있다.
Apps Script 는 `BUILD_INDEX_v15_교체용.gs` 로 바꾼다 (claude 폴더). v15 색인은
r='1'(알라딘 안 씀), h(검색용 알라딘 제목, 낮음만) 칸이 붙어 오고, 앱은 그대로 둔다.

**★ 폴더 탭은 색인의 제목·표지를 쓰지 않는다 (v34.1).**

색인 제목·표지는 알라딘에서 찾아 붙인 것이라, 짝을 잘못 지은 책이
폴더에 없는 다른 책처럼 보였다. 실시간은 실제 파일 이름, 색인은 색인 제목에 '색인 정보' 표시.
표지는 둘 다 끈다 (`exShow`). '새로' 는 색인을 만든 뒤 드라이브에 들어온 파일에만.
→ 다른 탭(전체·읽는 중…)의 엉뚱한 제목·표지는 Apps Script 의 알라딘 짝짓기를 손봐야 고쳐진다.

**★ 탐색기의 시작점은 관리 → '도서 폴더' 링크다.**

비어 있으면 실시간이 안 되고 색인으로만 보인다.
한 번 연 폴더는 `ebl_dirs` 에 기억한다 (1.5MB 넘으면 오래된 것부터 버림).
도서 폴더 이름은 `ebl_rootname` 에 한 번 받아 둔다. 폴더 이름을 바꿨으면 이 칸을 지워라.
색인 모드는 모든 책 경로의 맨 앞 한 겹이 같으면 그것을 도서 폴더로 본다.
NAS 는 `DIRSRC` 에 `list()` · `name()` 을 가진 갈래 하나를 더하면 된다.

**★ TXT 정리(`txtClean`)는 글자 수를 바꾸면 안 된다.**

TXT 형광펜은 글자 위치(c.s~c.e)로 저장된다. 정리는 줄바꿈→빈칸,
남는 빈 줄→U+200B 처럼 한 글자를 한 글자로만 바꾼다.
그래서 원문/정리본을 오가도 형광펜이 같은 자리에 있다. 길이가 바뀌는 규칙을 넣지 마라.

**★ 목록을 새로 받으면 정렬표(`ORD`)를 버린다.**

v31 까지는 안 버려서, 기기에 둔 목록 → 새 목록으로 바뀔 때
엉뚱한 순서로 보이고 새 책이 빠지기도 했다. `apply()` 맨 앞에서 비운다.

**★ 읽은 시간(`DAYS`)은 기기마다 따로 센다.**

`DAYS['날짜']['책ID|기기']=초`. 볼 때 더하고, 맞출 때는 칸마다 큰 값.
같은 칸을 두 기기가 같이 늘리면 겹쳐 세게 된다 — 기기 번호(`ebl_dev`)를 빼지 마라.
15초마다 세고, 5분 넘게 손을 안 대면 멈춘다. '기록 안 함' 책은 안 센다.

**★ 시작할 때 일찍 불릴 수 있는 값은 `var` 로 둔다.**

홈·폴더 탭은 앱이 다 읽히기 전에 그려질 수 있다. 아래쪽에서 `let/const` 로 만든 값을
거기서 쓰면 TDZ 로 멈춘다. v33 의 `DAYS`·`SORTN`·`TABN` 이 그래서 `var` 다.

**★ 읽어주기는 한 문장씩 준다.**

길게 주면 크롬은 15초쯤에서 끊고, 사파리는 pause/resume 이 불안하다.
그래서 문장(200자 안쪽)마다 `speak()` 하고, 멈춤은 `cancel()` 뒤 그 문장부터 다시 읽는다.
`TTS.gen` 번호로 취소된 문장의 onend 가 다음 문장을 부르지 않게 막는다.
문장 표시(`ttsShow`)가 실패해도 읽기는 계속된다 — 감싸 둔 try 를 빼지 마라.

**★ 최상위에서 `ME` 를 건드리지 마라.**

`let ME` 는 3,500줄쯤에 있다. 그보다 위에서 `ME.grp=...` 를 쓰면
TDZ 로 스크립트가 통째로 죽는다. 이것도 당했다.

## 6. 확인하는 법

고친 뒤 이것들을 돌리면 위의 사고를 대부분 잡는다.

```
문법 · id 참조 · 빈 버튼         index.html 을 훑는다
진짜로 뜨는지 (jsdom)            TDZ·이름겹침을 잡는다  ← 제일 중요
설정 화면 오가기                 뒤로·닫기·권한별 단추
로그인 이어가기                  닫았다 열기, 만료, 계정 여럿
Apps Script 통로                가짜 GAS 로 doGet 을 실제로 부른다
```

마지막 것이 특히 값어치가 있다. 배포하지 않고도
**다른 모임 글이 안 섞이는지**를 확인할 수 있다.

## 7. 문제가 생기면

| 증상 | 볼 곳 |
|---|---|
| 고친 게 안 보인다 | sw.js 의 V 를 올렸나 |
| '시작하는 중…' 에서 멈춤 | 이름 겹침. 화면에 줄 번호가 나온다 |
| 목록이 안 온다 | 관리 → 기록. 토큰이 맞나 |
| 로그인이 자꾸 풀린다 | 기본설정의 '구글 로그인' 줄에 까닭이 적힌다 |
| `Unexpected token '<'` | 웹앱 주소가 비었다. 자기 자신을 부른 것 |
| 기기를 바꿨다 | 관리 → [구글 계정에서 설정 가져오기] |
| 모임이 안 보인다 | 관리자 열쇠가 들어 있나 (`isOwner()`) |
| 모임 칸이 비어 있다 | Apps Script `FAM_SHOW()` |

## 8. Apps Script 함수

편집기 왼쪽에서 골라 실행한다. 밑줄로 시작하는 것은 목록에 안 나온다.

```
[책 모으기]
  START_FROM_EXTRACT   추출부터 알라딘까지
  CONTINUE  STOP  STATUS
  INSTALL_WATCHDOG     끊기면 자동으로 이어간다
  BUILD_INDEX          시트 → 색인 파일 (앱이 이걸 받는다)

[열쇠]
  MAKE_TOKEN           쓸 만한 토큰을 지어준다
  SET_WEBAPP_TOKEN     토큰 바꾸기
```
